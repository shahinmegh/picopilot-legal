# PI Copilot — legal documents

Public home for the documents an Atlassian administrator needs before
installing [PI Copilot](https://developer.atlassian.com/console), a SAFe
Program Increment capacity and velocity planner for Jira Cloud.

- [Privacy policy](privacy.md)

PI Copilot runs entirely on Atlassian infrastructure. It declares no egress
permissions, so the platform itself prevents it from sending anything
anywhere — including to us.
